# RYA-CAM Looksmaxing Demo

This repository contains a simple front-end demo for a looksmaxing face photo editor.
Users can upload one face image, receive a random hierarchy rating, and simulate how
cosmetic procedures or alternate hierarchies might affect the result.

## Usage

1. Open `index.html` in a modern browser.
2. Upload a single face image.
3. View the randomly assigned rating (LTN, MTN, HTN, Chadlite, Chad, Adam).
4. Toggle cosmetic procedure checkboxes and click **Apply Procedures** to see the adjusted rating.
5. Choose a different hierarchy from the dropdown and click **Simulate** to preview that ranking.

This project is for entertainment purposes only and does not perform real facial analysis.
